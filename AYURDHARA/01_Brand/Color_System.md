# Color System

## Core Brand Colors
- **Primary Green:** `#2E7D32`
- **Light Green:** `#8BC34A`
- **Cream:** `#FFFBEA`
- **Premium Gold Accent:** `#C9A227`
- **Dark Charcoal Text:** `#2D2D2D`

## Variant Colors
- **Kids:** Fresh Sage Green
- **Men:** Deep Navy Blue
- **Women:** Elegant Rose
- **Senior:** Warm Walnut Brown

## Application Rules
- **Primary Backgrounds:** Warm Ivory, Cream White, Soft Natural Paper.
- **Primary Text:** Deep Forest Green or Dark Charcoal.
- **Accents:** Premium Gold.
- **Constraints:** Never oversaturate colors. Never use neon colors. Never use random gradients.
