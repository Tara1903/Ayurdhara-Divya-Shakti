# Typography

Typography is the hero of the brand design.

- **Headings:** Cinzel Bold (Elegant & Premium)
- **Subheadings:** Montserrat SemiBold
- **Body Text:** Poppins Regular

## Application Rules
- Use elegant serif fonts (Cinzel) for branding and core headings.
- Use modern sans-serif fonts (Montserrat, Poppins) for information.
- Use different font weights to create hierarchy.
- **Constraints:** Never use decorative fonts. Never use childish fonts. Never use more than two font families. Typography should be readable on all label specifications.
